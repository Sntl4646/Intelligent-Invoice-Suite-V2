SECTION 4: LINE ITEMS - UNIVERSAL PATTERNS
═══════════════════════════════════════════════════════════

RECOGNIZE LINE ITEMS BY SEMANTIC MEANING ACROSS ALL INDUSTRIES

LINE ITEM TYPES BY INDUSTRY:

1. PRODUCT-BASED (Retail, Wholesale, Manufacturing):
   - Description: Product name, SKU, model number
   - Quantity: Units purchased
   - Unit Price: Price per item
   - Line Total: Quantity × Unit Price

2. SERVICE-BASED (Consulting, Professional Services):
   - Description: Service type, deliverable, task description
   - Quantity: Hours, days, sessions
   - Unit Price: Hourly/daily rate
   - Line Total: Hours × Rate
   - May include: Date of service, staff member name

3. SUBSCRIPTION/RECURRING (SaaS, Memberships):
   - Description: Plan name, subscription tier, license count
   - Quantity: Number of users/seats
   - Unit Price: Per user/month cost
   - Line Total: Monthly/annual charge
   - Period: Billing cycle dates

4. UTILITY (Electricity, Water, Gas, Telecom):
   - Description: Service type, meter reading, usage tier
   - Quantity: kWh, gallons, minutes, GB
   - Unit Price: Rate per unit (may be tiered)
   - Line Total: Usage charges
   - Additional: Fixed charges, connection fees

5. RENTAL/LEASE (Equipment, Uniforms, Vehicles):
   - Description: Item rented, asset ID
   - Quantity: Number of items, rental duration
   - Unit Price: Daily/weekly/monthly rate
   - Line Total: Rental charges
   - Additional: Damage fees, cleaning charges

6. MEDICAL/HEALTHCARE:
   - Description: Procedure code (CPT), service description, medication
   - Quantity: Number of visits, units, doses
   - Unit Price: Service fee, copay
   - Line Total: Charge amount
   - Additional: Insurance adjustments, patient responsibility

7. CONSTRUCTION/CONTRACTOR:
   - Description: Labor, materials, equipment
   - Quantity: Hours, units, square footage
   - Unit Price: Rate or unit cost
   - Line Total: Charge per line
   - May include: Phase, milestone, labor category

8. FEES/CHARGES (No quantity):
   - Description: Fee name (delivery, processing, late fee, tax)
   - Line Total: Fixed amount
   - No quantity or unit price

Column Name Variations (Same as before):

QUANTITY:
- Labels: "QTY", "Qty", "Quantity", "Hours", "Units", "Count", "Usage", "Duration", "Sessions"
- Data: Numbers, may include decimals
- Units: pcs, hrs, days, GB, kWh, kg, gallons, minutes

DESCRIPTION:
- Labels: "Description", "Item", "Service", "Product", "Charge Description", "Details", "Particulars"
- Data: Text field with item/service details
- May include: Codes (SKU, CPT, item code), dates, specifications

UNIT PRICE/RATE:
- Labels: "Unit Price", "Rate", "Price", "Fee", "Cost per Unit", "Hourly Rate", "Per Unit"
- Data: Decimal numbers
- Context: "per hour", "per item", "per kWh", "per user/month"

LINE TOTAL/AMOUNT:
- Labels: "Amount", "Total", "Line Total", "Charge", "Extended Price", "Subtotal"
- Data: Calculated amount
- Position: Rightmost column

ADDITIONAL METADATA (Industry-Specific):
- Date/Period: Service date, billing period, rental period
- Personnel: Employee ID, technician name, consultant
- Location: Site, property, meter location
- Codes: CPT codes, HS codes, SKU, product codes
- Status: Completed, pending, approved
- Category: Expense category, cost center, department

LINE ITEM FORMATS:

1. STANDARD TABLE:
   | Description | Qty | Rate | Amount |
   One row per item

2. GROUPED BY CATEGORY:
   "Labor Charges"
     - Item 1
     - Item 2
     Subtotal: $X
   "Materials"
     - Item 3
     - Item 4
     Subtotal: $Y

3. GROUPED BY DATE/PERIOD:
   "Week of Jan 1-7"
     - Service entries
   "Week of Jan 8-14"
     - Service entries

4. EMPLOYEE/USER-BASED (Same as before):
   Employee/User → Multiple items → Subtotal

5. TIERED USAGE (Utilities):
   "First 500 kWh @ $0.12 = $60"
   "Next 300 kWh @ $0.15 = $45"

6. PARAGRAPH/LIST FORMAT:
   "Monthly subscription fee ........... $99.00"
   "Additional user licenses (5) ...... $250.00"

7. TIME-BASED ENTRIES:
   Date | Description | Hours | Rate | Amount
   01/15 | Consultation | 2.5 | $150 | $375

VALIDATION FOR DIFFERENT TYPES:
- Products/Services: quantity × unit_price ≈ line_total
- Subscriptions: Check against billing period
- Utilities: Validate usage calculations and tiered rates
- Time-based: hours × hourly_rate ≈ amount
